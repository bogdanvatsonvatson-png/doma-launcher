DOMA_LAUNCHER — проект лаунчера Minecraft Java Edition для Windows
================================================================

Что есть:
- Тёмный интерфейс с названием doma_launcher.
- Получение списка официальных релизов и снапшотов.
- Выбор версии.
- Установка файлов выбранной версии и запуск Minecraft.
- Задел для входа Microsoft через защищённый PKCE-процесс.

ВАЖНО
-----
Это исходный проект, а не готовый .exe. В этой среде нельзя надёжно собрать
и проверить Windows .exe. Файл build.bat собирает его на Windows.

Для игры нужен купленный Minecraft Java Edition и корректно настроенный
Microsoft-вход. Не вводите пароль Microsoft в само приложение: вход открывается
в браузере Microsoft. Токены в этой стартовой версии хранятся в локальном
config.json без шифрования; не используйте её на общем компьютере и удалите
%USERPROFILE%\.doma_launcher\config.json, чтобы очистить сохранённую сессию.

Настройка Microsoft-входа
------------------------
1. Создайте приложение в Microsoft Entra/Azure и настройте его для входа
   личных Microsoft-аккаунтов.
2. Добавьте Redirect URI: http://localhost:8080 (должен совпадать точно).
3. Укажите Client ID в начале app.py вместо
   PASTE_YOUR_MICROSOFT_CLIENT_ID_HERE.
4. Доступ к Minecraft API может требовать отдельного разрешения/одобрения.
   Если Microsoft/Minecraft API не разрешает приложению вход, лаунчер не
   сможет авторизовать аккаунт, даже если интерфейс запускается.
5. После изменения app.py пересоберите приложение.

Сборка на Windows
-----------------
1. Установите Python 3.11 или новее с python.org, отметьте Add Python to PATH.
2. Распакуйте архив в отдельную папку.
3. Дважды нажмите build.bat.
4. Готовый файл появится в dist\\doma_launcher.exe.

Запуск из исходников
--------------------
В папке проекта откройте CMD:
    py -m pip install -r requirements.txt
    py app.py

Используются minecraft-launcher-lib и официальные файлы Minecraft.
Проект не содержит файлов самой игры.


Сборка EXE в облаке (если нет Windows-компьютера)
-------------------------------------------------
1. Создайте новый пустой репозиторий на GitHub.
2. Загрузите в него содержимое этой папки, включая скрытую папку .github.
3. Откройте вкладку Actions и запустите workflow "Build doma_launcher Windows app and installer"
   (или отправьте файлы в ветку main).
4. После успешной сборки откройте результат запуска workflow и скачайте
   artifact "doma_launcher-installer" (установщик doma_launcher_setup.exe)
   или "doma_launcher-portable" (переносимый doma_launcher.exe).

Это всё ещё сборка проекта, а не гарантия рабочего Microsoft-входа:
Client ID и разрешения Minecraft API необходимо настроить отдельно.


Обновлённый интерфейс:
- Вкладки Играть, Клиенты, Папки и моды, Оформление.
- Выбор акцентного цвета.
- Управление корневой папкой игры и создание папок mods/resourcepacks/shaderpacks/saves/config/logs/versions.
- Вкладка Клиенты содержит варианты для оптимизации и легальных модификаций.


Обновлённый интерфейс
---------------------
- Боковое меню с плавным переключением страниц.
- Вкладка «Клиенты» с официальными ссылками на Lunar Client, Badlion Client,
  Modrinth, AxolotlClient и Bewisclient.
- Вкладка «Папки игры»: корневая папка .minecraft, mods, resourcepacks,
  shaderpacks, versions, saves, screenshots, config, logs, crash-reports.
- Вкладка «Оформление» с готовыми цветами и выбором своего цвета.
- Кнопка «Создать отсутствующие папки» создаёт стандартные папки Minecraft.


Вариант 2: установщик Windows
-----------------------------
В папке installer лежит сценарий Inno Setup. После успешной сборки через
GitHub Actions скачайте artifact "doma_launcher-installer". Это установщик
doma_launcher_setup.exe: он устанавливает приложение в Program Files (или
выбранную папку), добавляет пункт меню Пуск и по желанию ярлык на рабочий стол.
Также можно скачать artifact "doma_launcher-portable" для одного переносимого
doma_launcher.exe без установщика.

Установщик сам по себе не заменяет настройку Microsoft Client ID / Minecraft
API и не включает в себя игровые файлы Minecraft.
